# Integration artwork

`irrigation-icon-source.png` is the original PNG generated with the built-in image generation tool.
The integration bundles transparent 256 × 256 and 512 × 512 PNG versions in
`custom_components/hunter_node_bt/brand/`. The previous droplet/Bluetooth SVG was removed because it
does not represent the new artwork.

This is independent project artwork, not an official Hunter or Hydrawise logo. Generation does not
establish legal clearance or guarantee uniqueness.

## Generation prompt

Use case: logo-brand. Asset type: square Home Assistant custom irrigation integration icon, production PNG. Create an original bold blue irrigation emblem with the professional, utilitarian feel of irrigation equipment branding. Subject: a compact sprinkler head at bottom center emitting three graceful thick water streams, with a small simple leaf integrated into the central stream. Flat vector-like silhouette, solid medium irrigation blue and a small teal accent, crisp smooth edges, generous negative space, centered square composition with 10 percent padding. Readable at 48px. Genuinely transparent background. No text, no letters, no wordmark, no border, no gradients, no shadows, no mockup. Do not reproduce Hunter or Hydrawise logos, their typography, or their distinctive logo shapes. This must be an independent project emblem, not an official manufacturer logo.

## Home Assistant support

Local brand images are supported starting with Home Assistant 2026.3, without manifest changes.
See the [Home Assistant announcement](https://developers.home-assistant.io/blog/2026/02/24/brands-proxy-api/).
